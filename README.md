# cad-desk-organizer
This is a *simple* and <ins>very useful</ins> desk organizer that has laid out sections for the most **important/most used items in an everyday office setting**. I created the desk organizer so that, first of all, I can use it myself, but also I think it's a fun project that took a lot of time because I had to make the correct dimensions using my digital calipers. At the end of the day this project was indeed fun to do and I put a lot of effort into the research behind it.
